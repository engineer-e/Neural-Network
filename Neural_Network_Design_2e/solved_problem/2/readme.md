# 2. Neuron Model and Network Architecture


1. The input to a single-input neuron is 2.0, its weight is 2.3 and its bias is -3.
    1. What is the net input to the transfer function?
    2. What is the neuron output?

2. What is the output of the neuron of P2.1, if it has the following transfer function?
    1. Hard limit
    2. Linear
    3. Log-sigmoid

3. Given a two-input neuron with the following parameters: b = 1.2, W = [3 2], and p = [-5 6]ᵀ, Calculate the neuron output for the following transfer functions
    1. A symmetrical hard limit transfer function
    2. A saturation linear transfer function
    3. A hyperbolic tangent sigmoid (tansig) transfer function

4. A single-layer neural network is to have six inputs and two outputs. The outputs are to be limited to and continuous over the range 0 to 1. What can you tell about the network architecture?
    1. How many neurons are required?
    2. What are the dimensions of the weight matrix?
    3. What kind of transfer functions could be used?
    4. Is a bias required?
